    Домашние задания

    Крепится отдельно для каждого класса

    Домашние задания крепятся отдельно для каждого класса и их можно добавлять сколько угодно: переключите класс в журнале — панель покажет все задания этого класса. Enter в поле текста добавляет задание, Shift+Enter — новая строка. Каждое задание остаётся закреплённым, пока его не уберут кнопкой «×».

    Enter — добавить задание, можно сколько угодно

    Синхронизация устройств

    Локальное сохранение работает и без подключения

    На этом устройстве

    На всех устройствах укажите один и тот же ID GitHub Gist: непубличного (Secret) или публичного (Public). На новом устройстве нажмите «Сохранить подключение» — существующий журнал загрузится автоматически. Токен и ID сохраняются в этом браузере и не сбрасываются после закрытия вкладки. Secret Gist доступен всем, у кого есть его ссылка.

    Для записи в Gist создайте Personal Access Token с правом gist. Без токена журнал откроется в режиме «только чтение» из публичного Gist.

    Публичный Gist читают все, кто знает его адрес. Не публикуйте персональные данные учеников.

    При переходе на эту версию обновите HTML на всех устройствах. Старая версия не читает новый формат синхронизации.

    Настройки журнала
    
    
    Настройки общие для подключённых устройств. Эта автономная версия предназначена для доверенных пользователей.
    
    
    
    
    
    
    Информационное сообщение на остальных устройствах. Управление настройками остаётся доступным.
    
    
    Список устройств, которые записывали журнал в этот Gist. Имя и роль можно задать вручную — они сохранятся в облаке для всех подключённых устройств.
    УстройствоАктивностьИмя устройстваРольТех. адм.
    Подключите Gist в разделе «Синхронизация», чтобы увидеть список устройств.
    
    
    Каждое учреждение — отдельный журнал с собственными данными на этом устройстве. Переключение открывает точную копию страницы, но с данными выбранного учреждения (ученики, классы, отметки, синхронизация и настройки не смешиваются). Добавление и удаление доступны учителю и тех. администрации; при удалении стираются все данные учреждения на этом устройстве.
    
    
    Классы можно переименовывать (новое название синхронизируется на все устройства) и удалять. Удаление класса помечает его как удалённый во всех синхронизированных устройствах: класс исчезает из выбора, а ученики, занятия и домашние задания этого класса удаляются вместе с ним (история отметок сохраняется в резервной копии). Доступно учителю и тех. администрации. Перед удалением автоматически сохраняется копия.
    Список классов пуст.
    Удаляет всех учеников, все отметки и пропуски, домашние задания и занятия во всех классах. Классы и предметы остаются. Перед очисткой автоматически сохраняется резервная копия — её можно восстановить кнопкой «Восстановить последнюю».
    
    
    Копии содержат учеников, отметки и настройки. Перед заменой данных сохраняются три последние версии.
    
    
    Аккаунты, созданные на экране входа/регистрации этого устройства. Удаление убирает учётную запись навсегда: войти по ней станет невозможно, а текущая сессия удалённого пользователя завершится. Перед удалением сохраняется резервная копия журнала.
    Пока нет ни одного аккаунта — пользователи создаются на экране входа.
